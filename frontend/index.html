Agenda técnica centralizada.

Como usar

  1. Cadastre seus clientes.
  2. Crie um agendamento e selecione o cliente, serviço, data e horário.
  3. Use WhatsApp para abrir uma mensagem pronta e envie após revisar.
  4. Em Agendamentos, use Imprimir / PDF para salvar os dados em PDF.
  5. Exporte CSV periodicamente como cópia de segurança.

Lembretes: esta versão não envia notificações automáticas com a página fechada. WhatsApp exige revisão e envio manual. Os dados ficam no PostgreSQL online.

Privacidade: use uma senha forte e não compartilhe o login.
